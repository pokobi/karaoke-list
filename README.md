# karaoke-list

カラオケで歌う曲を、音域とキーとあわせて管理する Web アプリ。

## 機能

- ログインは任意。ログインしないときはこの端末のブラウザに保存し、Google アカウントでログインすると複数の端末で同じリストを使える。ログインする前に保存した曲は、ログインしたあとにアカウントへ移せる（同じアーティスト・曲名の曲は追加しない）。ログアウトすると、この端末のリストに戻る
- 曲の登録・編集・削除（アーティスト、曲名、最低音・地声最高音・裏声最高音、キー）
- 一覧からのキー変更（±1、原キー、オク下・オク上）。キーに合わせて音域の表示も変わる。オク下・オク上のときは、カラオケ機で設定するキーと実際のキーを分けて表示する
- 自分の音域にもとづくおすすめキーの表示
- 曲の詳細画面・登録画面から、「アーティスト名 曲名 音域」での Web 検索（Startpage を使い、Google アカウントの検索履歴には残らない）
- 曲の詳細画面での試聴。この端末に保存した音楽ファイルを、今のキーに合わせて音の高さだけ変えて再生する（テンポは変えない）。再生中のキー変更にも追従し、原曲キーと聴き比べられる。PC など、マウスで操作する端末では音量も変えられる。ファイルはこの端末にだけ保存する
- 検索、アーティスト・タグ・お気に入り・音域（未入力を含む）での絞り込み、並び替え
- アーティスト名・曲名の入力候補（登録済みの名前と iTunes の検索結果）
- ジャケット画像の表示。曲名の候補から設定するほか、未設定の曲は iTunes からまとめて取得できる
- テキストからのまとめての追加。メモなどに書いた曲の一覧を貼り付けると、1 行ずつ iTunes で調べてアーティスト名・曲名・ジャケット画像を入れ、確認・修正してから追加する。区切りの記号やアーティスト名と曲名の順番がばらばらでも読み取り、よく使われるアーティストの略称にも対応する。確認画面で選び直した略称は覚えて、次から使う
- Google Takeout の YouTube Music 再生履歴から、よく聴いている曲を選んで追加
- お気に入り、タグ、採点、メモ、歌った回数・最終歌唱日の記録。歌った回数は一覧にも表示する
- タグの管理（作成・名前の変更・削除・並べ替え・色の設定）。曲の詳細画面での付け外しと、一覧で選んだ複数の曲へのまとめての付け外しに対応
- 一覧で複数の曲を選んで、タグ・お気に入り・削除をまとめて操作
- 一覧の行のスワイプ操作（右：歌った回数の記録、左：お気に入りの切り替え）。設定で無効にできる
- スマホでの触覚フィードバック（キーの変更、歌った回数の記録、お気に入りの切り替え）。設定で全体と操作ごとのオン・オフを選べる
- 表示の設定：テーマ（端末に合わせる・ライト・ダーク）、一覧の文字の大きさ、アクセントカラー、音域の表記（カラオケ表記・G4 形式・両方）、おすすめキーの余裕
- ランダム選曲。先に条件（アーティスト・タグ・お気に入り・自分の音域で歌えるか・最近歌った曲・音域の高さ）と曲数を決めてから選ぶ。1 曲または複数曲をまとめて選べ、歌った回数が少ない曲を出やすくすることもできる。結果が出るときの演出（スロット・リール・カード）を設定で選べる
- CSV の書き出し・読み込み
- ホーム画面への追加（PWA）、オフラインでの表示

## 構成

- HTML / CSS / JavaScript（ビルドなし）
- Firebase Authentication（Google ログイン。任意）
- Cloud Firestore（ログインしたときの保存先。端末内キャッシュあり）
- localStorage（ログインしていないときの保存先）
- iTunes Search API（入力候補・ジャケット画像）
- Web Audio API（AudioWorklet）による音の高さの変換（試聴のキー変更）
- [fflate](https://github.com/101arrowz/fflate)（Takeout の ZIP の展開。ライセンスは `js/vendor/fflate.LICENSE`）

## セットアップ

1. Firebase プロジェクトを作成し、ウェブアプリを登録する
2. Authentication で Google ログインを有効にし、公開先のドメインを承認済みドメインに追加する
3. Firestore Database を作成し、`firestore.rules` の内容をルールに設定する
4. `js/config.js` の `FIREBASE_CONFIG` に firebaseConfig を設定する

`FIREBASE_CONFIG` が `null` の場合は、ログインの機能を使わず、ブラウザ内にだけ保存するローカルモードで動作する。
