# karaoke-list

カラオケで歌う曲を、音域とキーとあわせて管理する Web アプリ。

https://pokobi.github.io/karaoke-list/

## 機能

### 曲の管理

- 曲の登録・編集・削除（アーティスト名、曲名、最低音・地声最高音・裏声最高音、キー）
- アーティスト名・曲名の入力候補とジャケット画像（登録済みの名前と iTunes の検索結果から）。画像が未設定の曲は、まとめて取得できる
- テキストからのまとめての追加。メモなどに書いた曲の一覧を貼り付けると、1 行ずつ iTunes で調べ、確認・修正してから追加する。区切りや順番がばらばらな書き方や、よく使われるアーティストの略称も読み取る。確認画面で選び直した略称は覚えて、次から使う
- YouTube Music の再生履歴（Google Takeout）から、よく聴いている曲を選んで追加
- お気に入り、タグ（色の設定・並べ替えを含む）、採点、メモ、歌った回数・最終歌唱日
- 一覧で複数の曲を選んでのまとめての操作（タグ・お気に入り・削除）と、行のスワイプ操作（歌った回数の記録・お気に入りの切り替え）
- CSV の書き出し・読み込み

### キーと音域

- 一覧・詳細画面からのキー変更（±1、原キー、オク下・オク上）。キーに合わせて音域の表示も変わる。オク下・オク上のときは、カラオケ機で設定するキーと実際のキーを分けて表示する
- 自分の音域にもとづくおすすめキー。曲の地声最高音が、自分の地声最高音より設定した分だけ低くなるキーをおすすめする。最低音や裏声最高音などが自分の音域を超えるときは、はみ出しの大きさに応じた色で注意を表示する
- 「アーティスト名 曲名 音域」での Web 検索（Google アカウントの検索履歴に残らない DuckDuckGo を使う）

### 試聴

- iTunes の試聴（曲の一部）か、この端末に保存した音楽ファイルを、今のキーに合わせて音の高さだけ変えて再生する（テンポは変えない）。オク下・オク上の分は入れず、カラオケ機で設定するキーだけ変えて再生する（大きく変えると音が歪むため）
- 原曲キーとの聴き比べ、再生中のキー変更への追従、PC などマウスで操作する端末での音量調整
- iTunes の試聴では、使う曲を自動で選び（ライブ版などより元の版を優先）、ほかの版に選び直せる。Apple Music のバッジとその曲へのリンクを添える
- 音楽ファイルはこの端末にだけ保存する

### 探す・選ぶ

- 検索、絞り込み（アーティスト・タグ・お気に入り・音域）、並び替え
- ランダム選曲。条件（アーティスト・タグ・お気に入り・自分の音域で歌えるか・最近歌った曲・音域の高さ）と曲数を決めてから選ぶ。歌った回数が少ない曲を出やすくでき、結果が出るときの演出（スロット・リール・カード）も選べる

### 保存と同期

- ログインは任意。ログインしないときは、この端末のブラウザに保存する
- Google アカウントでログインすると、複数の端末で同じリストを使える。ログインする前に保存した曲は、ログインしたあとにアカウントへ移せる（同じアーティスト・曲名の曲は追加しない）。ログアウトすると、この端末のリストに戻る
- ホーム画面への追加（PWA）、オフラインでの表示。Android でホーム画面に追加して使うときは、外部のページを規定のブラウザで開く

### 表示

- テーマ（端末に合わせる・ライト・ダーク）、一覧の文字の大きさ、アクセントカラー、音域の表記（カラオケ表記・G4 形式・両方）
- スマホでの触覚フィードバック（キーの変更、歌った回数の記録、お気に入りの切り替えなど）。操作ごとにオン・オフを選べる

## 構成

- HTML / CSS / JavaScript（ビルドなし）
- Firebase Authentication（Google ログイン。任意）
- Cloud Firestore（ログインしたときの保存先。端末内キャッシュあり）
- localStorage（ログインしていないときの保存先）、IndexedDB（試聴の音楽ファイルの保存先）
- iTunes Search API（入力候補・ジャケット画像・試聴）
- Web Audio API（AudioWorklet）による音の高さの変換（試聴のキー変更）
- [fflate](https://github.com/101arrowz/fflate)（Takeout の ZIP の展開。ライセンスは `js/vendor/fflate.LICENSE`）

## セットアップ

1. Firebase プロジェクトを作成し、ウェブアプリを登録する
2. Authentication で Google ログインを有効にし、公開先のドメインを承認済みドメインに追加する
3. Firestore Database を作成し、`firestore.rules` の内容をルールに設定する
4. `js/config.js` の `FIREBASE_CONFIG` に firebaseConfig を設定する

`FIREBASE_CONFIG` が `null` の場合は、ログインの機能を使わず、ブラウザ内にだけ保存するローカルモードで動作する。
